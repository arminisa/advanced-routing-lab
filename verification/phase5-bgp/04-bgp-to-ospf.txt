PHASE 5 - BGP - 04: REDISTRIBUTION (BGP → OSPF)
================================================================
Project: advanced-routing-lab
Date: 2026-10-08

----------------------------------------------------------------
CONFIGURATION - R1-Core
----------------------------------------------------------------

router ospf 1
 redistribute bgp 65001 subnets
 network 10.0.100.0 0.0.0.3 area 0

----------------------------------------------------------------
KEY CONFIG NOTES
----------------------------------------------------------------

1. "subnets" keyword is MANDATORY:
   - Without it: only classful networks (/8, /16, /24)
   - With it: ALL subnets including /30, /32 pass through
   - Loopback ISP (9.9.9.9/32) needs this to be redistributed

2. Link to R-ISP (10.0.100.0/30) must be in OSPF:
   - Without this: R2 has no return path to 10.0.100.2
   - Result: traceroute works but ping fails (asymmetric routing)
   - R1-Core itself has "C" (connected) route, but R2 doesn't
