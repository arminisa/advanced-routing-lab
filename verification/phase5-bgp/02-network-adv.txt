CONFIGURATION
----------------------------------------------------------------

R1-Core (AS 65001):
 router bgp 65001
  network 1.1.1.1 mask 255.255.255.255

R-ISP (AS 65002):
 router bgp 65002
  network 9.9.9.9 mask 255.255.255.255

----------------------------------------------------------------
KEY NOTES
----------------------------------------------------------------

BGP "network" command is DIFFERENT from OSPF/EIGRP:
- OSPF/EIGRP: "network" activates interfaces for the protocol
- BGP: "network" advertises an EXISTING route from RIB

CONDITION:
The prefix must already exist in the routing table (as connected,
static, or IGP route). Otherwise it won't be advertised.
